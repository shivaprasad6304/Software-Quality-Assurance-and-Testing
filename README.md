# Software-Quality-Assurance-and-Testing
HOSPITAL MANAGEMENT SYSTEM 
The Hospital Management System has been developed in terms of industry standard
technologies which are chosen based on the needs of the healthcare system. Java EE was the
major backend framework, and this gave it the high-level of robustness, security features and
enterprise grade of reliability necessary in medical apps. JAVAServer Pages (JSP) was used
to generate dynamic web content in an integrated plug and play manner with Java. Apache
Tomcat 8.5+ was used as the application server which has provided lightweight deployment
and good support of JSP. MySQL 5.7+ assisted the database base of relational databases with
compliance to the ACID where data integrity is guaranteed. All the inter-tier communication
was based on HTTPS that encrypts traffic.
